5. WARNA TRANSPARANSI, SHADOW & EFEK (RGB / RGBA)
--------------------------------------------------------------------------------
• rgba(120, 170, 210, 0.3) : Grid Line Blue (garis kisi buku kotak-kotak pada latar belakang)
• rgba(0, 0, 0, 0.08)       : Drop shadow lembut untuk text-stroke 7px
• rgba(0, 0, 0, 0.06)       : Drop shadow lembut untuk text-stroke 5px
• rgba(0, 0, 0, 0.09)       : Bayangan halus layer pertama pada kartu notebook
• rgba(0, 0, 0, 0.04)       : Bayangan halus layer kedua pada kartu notebook
• rgba(0, 0, 0, 0.20)       : Bayangan dalam (inset shadow) untuk efek lubang ring buku
• rgba(0, 0, 0, 0.18)       : Drop shadow pada pin logam stiker
